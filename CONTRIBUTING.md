# Contributing to Hawxeys Awakening

This is living mythology. Treat contributions with the same seriousness.

## For Developers

1. Fork the repo
2. Create a feature branch
3. Develop and test locally
4. Commit with clear messages
5. Open a Pull Request

## For Content Creators

- Align with the Manifesto and core pillars
- Separate signal from story
- Prefer operational language over pure exceptionalism
- Keep the heart human and the standards strong

## Code of Conduct

- Radical honesty
- No ego inflation without proof
- Shadow material is data, not identity
- Respect the sacred nature of the work

Questions or proposals: open an issue.
