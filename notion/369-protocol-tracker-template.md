# 369 Protocol Tracker — Template

**45-Day Focused Repetition Cycle**

## Daily Structure

### Morning (3x)
Write or speak your core intention / affirmation three times.

### Afternoon (6x)
Write or speak the same six times. Mid-day recalibration.

### Evening (9x)
Write or speak nine times. Close the day in the frequency.

## Core Intention Examples (Hawxeys)

- I AM → focus → action → proof.
- I regulate emotional input and output without over-identifying with residual charge.
- I create from what remains after the shadow has been faced.
- Clarity, calm, and directed force increase daily.

## Tracking Columns (Notion Database Suggestion)

- Date
- Morning Completed (checkbox)
- Afternoon Completed
- Evening Completed
- Body State (energy / sleep / tension)
- Emotional Residue (what was carried)
- Insight / Pattern Noticed
- Creative Output (lyric / visual / action taken)
- Notes

## Milestone Markers

- Day 11 — First integration check
- Day 22 — Mid-cycle recalibration
- Day 33 — Deepening
- Day 45 — Full cycle review + next intention selection

Export weekly. Review patterns. Adjust. Repeat.
